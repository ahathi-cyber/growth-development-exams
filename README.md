# Pediatrics Growth & Development Practice Exams

A static revision site for Final MBBS paediatrics growth and development.

## Exam pages
- 30 True/False groups with 5 statements each.
- 30 Single Best Answer questions.
- Local results review and CSV export in the prototype.

## Important limitations
This first version is browser-only. Answers shipped to the browser are not secure for proctored exams. Results are not collected centrally. A secure backend such as Supabase is needed for server-side marking and a teacher dashboard.
